# 想約我的小日曆

這是一個給親近朋友看的行事曆與邀約初版。

## 目前功能

- 未登入也能看公開行事曆。
- 朋友登入後可以選擇邀約類型，例如來我家住、約吃飯、約出門、想聊天、單純留言。
- 朋友送出邀約時會綁定正確姓名。
- 你可以登入後台查看所有邀約、核准或婉拒。
- 核准時會產生一段可編輯的 Line 回覆公版。
- 後台可新增、編輯、停用邀約類型。
- 後台可新增、停用朋友帳號。

## 試用帳號

- 我的後台：admin / admin123
- 朋友帳號：mei / mei123
- 朋友帳號：yu / yu123

## 怎麼打開

直接用瀏覽器打開 `index.html` 就可以試用。

目前資料會存在自己的瀏覽器裡，適合先確認流程與畫面。之後正式版可以接 Supabase。

## 檔案說明

- `index.html`：網站畫面結構。
- `style.css`：清新自然無印風樣式。
- `app.js`：登入、邀約、後台管理等互動。
- `supabase-setup.sql`：之後建立 Supabase 資料表用。
- `supabase-delete-policy.sql`：之後重設 Supabase policy 或測試清理用。
- `favicon.svg`：網站小圖示。
